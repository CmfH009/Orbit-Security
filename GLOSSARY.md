# Orbit Security — Domain Glossary

Canonical domain language for `<REPO_ROOT>`. Use these exact terms in specs, code, ADRs, and PRs.

## Language

**Perimeter Audit**:
A scheduled or on-demand external attack-surface assessment run against a target agency or client domain, producing scored findings and evidence.
_Avoid_: scan job, security sweep, health check

**Blackboard**:
The decoupled SQLite WAL event mesh (`src/orbit_security/blackboard.py`) through which scanners, sentinels, and remediation workers publish and consume state.
_Avoid_: message queue, event db, sqlite bus

**AST Sentinel**:
The static symbol and import hygiene verifier (`src/orbit_security/ast_sentinel.py`, supports `--auto-fix`) guarding Python code integrity before merge.
_Avoid_: code linter, syntax checker

**Remediation Artifact**:
An autonomous fix bundle stored under `data/remediation/` consisting of a proposed code patch, correction note, and client-facing email draft generated by OpenCode remediation.
_Avoid_: fix dump, patch folder

**Landing Source**:
Editable marketing site files under `landing/` (`landing/input.css`, HTML, JS, media) compiled into `landing/assets/styles.min.css` via `npm run build:css`.
_Avoid_: web root, static site

**Published Docs**:
The generated GitHub Pages mirror under `docs/` synced strictly from **Landing Source** via `npm run sync:docs` and verified by `npm run check:landing`.
_Avoid_: editable site, docs source

## Relationships

- A **Perimeter Audit** publishes findings onto the **Blackboard**.
- Autonomous remediation consumes **Blackboard** findings and emits a **Remediation Artifact**.
- **Landing Source** compiles and syncs one-way into **Published Docs**.
